# Competitive Positioning Analysis Tool

## How to use
1. Paste competitor information into competitor-input.txt
   (website copy, messaging, taglines, product descriptions)
2. Run this prompt: "Read competitor-input.txt and analyse 
   it using the instructions in competitor-analysis.md. 
   Save the output to competitive-report.txt"

## Analysis Instructions

Read competitor-input.txt and produce a full competitive 
positioning report structured as follows:

### 1. Competitor Snapshot (one per competitor)
For each competitor found in the input:
- Company name
- Core value proposition (one sentence)
- Primary target audience
- Top 3 messages they lead with
- Tone of voice (3 words)
- What they emphasise most
- What they avoid or never mention
- Biggest apparent weakness in their positioning

### 2. Messaging Comparison Matrix
Create a comparison across all competitors for:
- How they talk about pricing
- How they talk about ease of use
- How they talk about enterprise readiness
- How they talk about integrations
- How they talk about compliance and security

For each category note: who owns it, who ignores it, 
who is weakest on it

### 3. Positioning Gaps Analysis
Identify:
- Messages no competitor is strongly owning
- Audience segments underserved by current messaging
- Pain points mentioned by none or few competitors
- Opportunities for SAP Concur to differentiate

### 4. SAP Concur Differentiation Angles
Based on the gaps identified, suggest:
- 3 positioning angles SAP Concur could own
- For each angle: the message, the proof point, 
  the target persona
- Which competitors this directly counters

### 5. Recommended Messaging Moves
- 2-3 specific changes to current SAP Concur messaging
- Which competitor weakness each move exploits
- Priority order: high / medium / low

### 6. Weekly Digest Summary
A 150-word executive summary suitable for sharing 
with a marketing team or CMO covering:
- Key competitive movements this week
- Biggest opportunity identified
- Recommended immediate action

## Output Format
- Save to competitive-report.txt
- Clear headers for each section
- Use bullet points for scannability
- End with the executive digest
- Flag the top 3 most important insights with [KEY INSIGHT]
