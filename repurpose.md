# Content Repurposing Tool

## How to use
1. Paste any blog post or article into input.txt
2. Run this prompt in Claude Code:
   "Read input.txt and repurpose it using the instructions in repurpose.md. Save the output to output.txt"

## Repurposing Instructions

Read the content in input.txt and transform it into all of the following:

### 1. LinkedIn Post
- 100-150 words
- Start with a hook — a bold statement or question
- Use 3-4 short paragraphs
- End with a call to action or thought-provoking question
- Add 3 relevant hashtags at the bottom

### 2. Tweet Variations (write 3)
- Under 280 characters each
- Variation 1: lead with the pain point
- Variation 2: lead with the benefit
- Variation 3: make it conversational or ask a question

### 3. Email
- Subject line: curiosity-driven, under 50 characters
- Preview text: expands on subject, under 90 characters
- Keep both punchy and relevant to the source content

### 4. Ad Headlines (write 3)
- Under 8 words each
- Direct, benefit-focused
- No fluff words

### 5. Instagram Caption
- 80-100 words
- Conversational and warm tone
- End with a question to drive comments
- Add 5 relevant hashtags

## Output Format
Save everything to a file called output.txt
Use clear headers for each section
Add a divider line between each section
